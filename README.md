# Glisten

Quality of life for **World of Warcraft: Forever**. Quest objectives and tracked nodes that
sparkle in the world, automatic quest accept and turn-in that picks the right reward for
your class, and one-key fishing. Every feature is optional.

This repository only holds release downloads. Type `/glisten` in game for the settings.

## Install With WowUp (Recommended)

1. In WowUp, select **World of Warcraft: Forever** as the client.
2. Go to **Get Addons** and choose **Install From URL**.
3. Paste `https://github.com/jfraygit/Glisten-Release` and install.

WowUp keeps Glisten updated from then on, like any other addon.

## Install By Hand

Download the zip from the latest [release](https://github.com/jfraygit/Glisten-Release/releases/latest)
and unzip it into:

```
World of Warcraft\_forever_\Interface\AddOns\
```

To update, unzip the new one over it. Your settings are kept.
